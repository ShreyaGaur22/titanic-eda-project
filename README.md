# Titanic Data Analysis — Pandas Assignment

## About
This repository contains my solutions to an assignment completed while learning Python's Pandas library.

The assignment uses the Titanic dataset to practise data
manipulation, data cleaning, grouping, and exploratory
data analysis.

## Topics Covered

- Loading and inspecting datasets
- Summary statistics
- Series, DataFrames, and conditional filtering
- Indexing with `loc` and `iloc`
- Sorting and selecting records
- Grouping, aggregation, and transformation
- Identifying and handling missing values
- Text processing and feature extraction
- Creating derived columns
- Duplicate detection and categorical data
- Merging and concatenating DataFrames
- Pivot tables and crosstabs
- Reshaping data using `melt()` and `unstack()`
- Exploring factors associated with passenger survival

## Tools Used
- Python
- Pandas
- Jupyter Notebook
